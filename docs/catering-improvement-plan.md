# תוכנית שיפור – מסך קייטרינג

קובץ עיקרי: `src/app/admin/catering/page.tsx`

## 1. הסרת מגבלת מנות עיקריות
- היום הקוד מחייב בדיוק 2 מנות (`meatsCount === 2`). נשנה לדרישה של מנה אחת לפחות, בלי תקרה.
- נסיר את "בחר 2" ואת "x/2" מהכותרת, מהתג ומהודעת השגיאה.
- נוסיף מנת דג קבועה ליד המנה הצמחונית: שם המנה ומספר מנות, באותו מבנה ובאותו עיצוב.

## 2. עריכת הזמנה קיימת
- נוסיף כפתור "ערוך" בארכיון. הוא ימלא את הטופס וישמור את מזהה ההזמנה.
- בשמירה: אם יש מזהה, ההזמנה הקיימת תתעדכן (`updateDoc`). אם אין, תיווצר הזמנה חדשה כמו היום.
- נוסיף פס עליון "עורך הזמנה מ-[תאריך]" עם כפתור "ביטול".

## 3. הקטנת ה-PDF (מ-10MB לפחות מ-1MB)
- נשמור את התמונה כ-JPEG באיכות 0.85 במקום PNG.
- נוריד את הרזולוציה (`scale`) מ-2 ל-1.5.
- נדחס את `public/logopage.png` (היום 1.2MB) לגרסה קלה של כ-150KB.

## 4. תצוגה בטאבלט
- טור אחד עד רוחב `xl` (במקום `lg`), כדי שבטאבלט לא יהיו שני טורים צפופים.
- נבטל את הרוחבים הקבועים (`w-[100px]`, `w-[500px]`).
- נבדוק בצילומי מסך ברוחב 768 וברוחב 1024 פיקסלים.

## 5. פחות עומס, כפתורים קטנים יותר
- כפתורים ברוחב התוכן במקום `w-full`, בגובה אחיד של כ-40px.
- שורת פעולות אחת: שמירה (כפתור ראשי), ו-WhatsApp, העתקה ו-PDF (כפתורים משניים).
- נקבץ את הטופס ל-3 חלקים ברורים: פרטים, מנות, תוספות. הסיכום יוצג בחלק מקופל.
- נסיר אפקטים ותגיות כפולות.
